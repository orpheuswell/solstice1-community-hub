New to Community BDAG Chain 1404? Start here. These short lessons explain the basics in everyday language. Examples describe how blockchain systems generally work; check the linked community resources for the current implementation and status.

Lesson 1 · Start here

⛓️ What is Community BDAG?

Community BDAG is an independently supported blockchain ecosystem using Chain ID 1404. It aims to let people send transactions and use community-built applications without depending on a single website or operator.

Remember: A blockchain network, a wallet balance, and a token's market value are different things. Development activity does not guarantee a future price or exchange listing.

Lesson 2 · Infrastructure

🌐 Nodes, RPCs and explorers

A node runs network software and helps maintain or check blockchain information. An RPC is a connection your wallet or app uses to ask a node for data or submit transactions. An explorer lets you look up public transactions and blocks.

Example: If one RPC website stops working, that does not automatically mean the entire network is offline. Check independent sources.

Lesson 3 · Mining

⛏️ How mining works

Miners use computing hardware to participate in the network's mining process. GPU and ASIC miners can join compatible pools, which combine mining work and distribute rewards according to the pool's rules.

Example: Solstice1 shares a public X30 ASIC mining dashboard so visitors can inspect reported mining activity. Mining rewards and electricity costs can change.

Lesson 4 · Safety

🔐 Wallets, fees and transactions

A wallet such as MetaMask lets you manage addresses and approve transactions. The network setting tells the wallet which chain to use. A transaction may require a network fee, often called gas.

Safety first: Never share your recovery phrase or private key. Check the network, destination address and wallet approval before signing. A displayed token name alone does not prove an asset is genuine.

Review network connections ↗
Lesson 5 · Applications

🌊 dApps, DEXs and liquidity

A decentralised application (dApp) interacts with blockchain contracts. A decentralised exchange (DEX) can let users swap supported tokens. Liquidity providers put assets into pools that support trading, but they take on risks including price changes and smart-contract faults.

Example: REEF DEX provides swaps, liquidity tools and token-launch features. A listing on a DEX is not proof that a token is safe or valuable.

Lesson 6 · Participation

🗳️ Testnet, staking and governance

A testnet is a separate place to try features before they are used more widely. Governance systems can let eligible participants vote on proposals. Staking and voting rules depend on the specific contract and network version.

Important: Community testnet BDAG has no monetary value. Never send real BDAG to a testnet address or assume a proposed mainnet feature is already live.
